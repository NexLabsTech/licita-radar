# LicitaRadar

Radar privado de uso individual para acompanhar contratações públicas de produtos divulgadas pelo PNCP.

**Estado:** início do projeto. Código, CI e documentação mínima serão construídos em PRs auditáveis. Nenhum dado de demonstração deve ser apresentado como oportunidade real.

Veja `docs/SOURCE_PACK.md` para requisitos essenciais e critérios de aceite. Variáveis de ambiente nunca devem ser publicadas no repositório.
