**OBJECTIVE:** ampliar a cobertura de publicações oficiais PNCP sem perder evidência de incompletude, permitindo usuário iniciar e continuar lotes paginados com filtro opcional por município IBGE.

**CONTEXT / SOURCES:** PNCP público sem chave; API Consultas v1.0, GET /v1/contratacoes/publicacao aceita codigoMunicipioIbge, uf, pagina, tamanhoPagina (https://www.gov.br/pncp/pt-br/pncp/manuais/ManualPNCPAPIConsultasVerso1.0.pdf/@@display-file/file); ver app/pncp.py, app/storage.py, app/main.py, app/templates/dashboard.html, app/static/site.css, scripts/visual_smoke.py, tests/test_mvp.py e CI.

**SCOPE / NECESSARY:** GET autenticado /coverage e /api/coverage; POST autenticado+CSRF /coverage/start e /coverage/next; até 20 jobs locais, filtros até 7 dias, UF, modalidade 6/8, código IBGE municipal opcional sete dígitos; até 2 páginas de 20 publicações por execução; cursor, progresso, estado, erro, data UTC persistidos; retomar após falha/restart e evitar duplicidade de itens via importação existente; exibir 'parcial', 'concluído' ou 'falha' sem prometer varredura exaustiva se API não comprovar fim. Sem credenciais, agendamento adicional ou egress em testes. **IMPORTANT futuro:** agendamento controlado multirregional, retrovarredura por município, exportação CSV; **OUT OF SCOPE:** scraping, integrações autenticadas, alteração do coletor auto existente, cobrir 100% dos órgãos fora PNCP, lances, deploy e novas despesas.

**REQUIREMENTS / RULES:** somente origem PNCP HTTPS fixa, paginação de tamanho 20, max 2 páginas por POST, resposta validada; cursor só avança com página processada sem erros; zero dados falsos se API falhar; limite de tamanho de resposta e rejeitar dados parciais; lote finaliza só em última página explícita ('paginasRestantes=0' ou página menor que 20), quando não houver erros; status 'incompleto' quando exceder orçamento do lote e houver mais páginas; nenhum status 'concluído' se fonte incerta. Preservar event/favoritos ao reimportar. Somente 1 sincronização por vez usando lock já existente. Sem JS perigoso ou URL arbitrária. Indexar histórico de progresso com limite 20 jobs, sem exclusão automática destrutiva.

**ACCEPTANCE CRITERIA:** código IBGE validado; nenhuma importação com filtro falso; reimportação idempotente; página incompleta reexecutada depois de erro; 2 x 20 máximo por chamada; fim provado e logs corretos; retorno HTTP 401/403/409 nos casos; HTML glass responsivo e browser desktop/mobile; fail-closed em estrutura PNCP anômala, sem avançar cursor.
